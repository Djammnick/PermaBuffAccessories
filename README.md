# PermaBuff Accessories

PermaBuff Accessories is a small utility mod for Terraria. It adds a vast selection of items that grant permanent versions of buffs in the form of an item.
The items are interweaved with the progression, with further tiers becoming available after major milestones.

The mod is available on the Steam Workshop and must be installed via [tModLoader](https://github.com/tModLoader/tModLoader).
